# Coverage

What of Qt 6.12.0's public API qtc binds, generated by `gen/coverage_md.py` from `manifest/coverage.json`. A method counts once per declaring class; overloads count separately.

| | |
|---|---|
| methods declared | 16,298 |
| methods bound | 12,421 (76.2%) |
| constructors bound | 1,009 |
| classes with bindings | 618 |

Without operators and moc internals, which C cannot name anyway, the share bound is 83.5%.
